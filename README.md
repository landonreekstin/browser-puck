# browser-puck

Team air hockey in the browser for 4–8 players. Each team has one goalie who launches the
puck slingshot-style, and blockers: rotating bars that deflect it toward the
opposing goal.

- Rules: [docs/DESIGN.md](docs/DESIGN.md)
- Plan: [docs/ROADMAP.md](docs/ROADMAP.md)
